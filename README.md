## Projects

**[autonomous-greenhouse](https://github.com/carlarubesp/autonomous-greenhouse)**
Autonomous greenhouse controller built on a MAPE-K loop. It monitors six environmental metrics, detects alarms and trends, and drives actuators using hysteresis and a priority hierarchy.
`Python` `MQTT` `FastAPI` `Docker`

**[billposting](https://github.com/carlarubesp/billposting)**
Business process orchestrated with Camunda 7 and Spring Boot, coordinating separate user, zone and posting services.
`Java` `Spring Boot` `Camunda` `BPMN`

**[KCASH2-mouse](https://github.com/carlarubesp/KCASH2-mouse)**
RNA-seq analysis pipeline studying the tumour suppressor KCASH2 in a colorectal cancer mouse model: preprocessing, differential expression with DESeq2, and GO/KEGG enrichment.
`R` `DESeq2` `Bioconductor`
